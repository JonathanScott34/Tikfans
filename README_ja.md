# 私たちについて
私たちはクリエイターのために生まれたストリーミング配信ネットワークです。

従来のプラットフォームでは、トラフィックはアルゴリズムによって決まり、収益は何層にもわたって差し引かれます。クリエイターと支援者の間には複雑な仕組みとルールが存在します。私たちはそれを変えたいと考えています。

分散型の決済、より高い収益分配率、そして直接的なフォロー関係によって、価値がクリエイターとユーザーの間を自由に流れる世界を実現します。

## 私たちがしていること
- 動画や記事を自由に公開
- オーディエンスへ直接課金
- 最大90%の収益を獲得
- 紹介メカニズムでプラットフォームの成長に参加し報酬を得る
- Web3ウォレットによるグローバルで許可不要な取引

プラットフォームは仲介者ではなく、ツールです。

## なぜ今なのか
クリエイターエコノミーは急速に拡大していますが、実際に大きな恩恵を受けている人はまだ限られています。次世代のプラットフォームは、よりオープンで、透明で、公平で、そしてグローバルであるべきです。

技術の準備は整いました。次はプロダクトとコミュニティの番です。

## 私たちのビジョン
創作を、長期的に積み上げることができ、真に所有され、継続的に価値を生み出す力にすること。

> クリエイターであっても、視聴者であっても、プロモーターであっても、誰もがエコシステムから正当な分配を受けるべきです。
