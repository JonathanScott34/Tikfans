# 关于我们
我们是一个为创作者而生的流媒体分发网络。

在传统平台中，流量由算法决定，收益被层层抽取，创作者与支持者之间隔着复杂的系统与规则。我们希望改变这一点。

通过去中心化的支付方式、更高比例的分成，以及更直接的关注关系，让价值在创作者与用户之间自由流动。

## 我们在做什么
- 自由发布视频与图文
- 直接向受众收费
- 获得高达 90% 的收入
- 通过推荐机制参与平台增长并获得回报
- 使用 Web3 钱包完成全球化、无需许可的交易

平台不是中介，而是工具。

## 为什么现在
创作者经济正在快速增长，但真正受益的人却仍然有限。下一代平台应该更加开放、透明、公平，并且面向全球。

技术已经准备好了，现在轮到产品和社区。

## 我们的愿景
让创作成为一种可以长期积累、被真正拥有、并持续产生价值的能力。

> 无论你是创作者、观众，还是传播者，都应该从生态中获得属于你的那一部分。
